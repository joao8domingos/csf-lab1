Ponteiro LFS: Repositórios Git que lidam com ficheiros pesados (como imagens grandes ou binários) usam frequentemente o Git LFS. Em vez de guardarem o binário da imagem no histórico normal do Git, guardam apenas um pequeno ficheiro de texto a indicar onde descarregar o ficheiro real (neste caso, através do URL do GitHub LFS com um identificador único sha256:29178488...).
O tamanho reduzido (131 bytes): Explica perfeitamente porque é que o comando file o classificava como "ASCII text".
